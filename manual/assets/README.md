# Capturas autorizadas

Estas dos capturas reales muestran Humanizador 0.5 durante una revisión del proyecto IAHPT. Roberto Canales Mora autorizó expresamente utilizar su proyecto actual como ejemplo para la presentación pública, el README y el manual el 9 de octubre de 2026.

- `revision-pdf.png`: captura aportada por el autor, con PDF, marcas y tabla de sugerencias.
- `navegacion-pdf.jpg`: detalle del control de página dentro del visor, capturado durante la comprobación de esa función.

El código y la documentación propia tienen licencia MIT. Los fragmentos del libro visibles en estas imágenes mantienen los derechos de Roberto Canales Mora y se incluyen únicamente para ilustrar el funcionamiento; no se relicencian como parte del software. No se distribuye el libro completo, la base de datos ni el registro de notas.

Las huellas de estas imágenes se fijan en `docs/capturas-publicas.json`. Cualquier captura adicional requiere revisar su contenido y actualizar ese manifiesto de forma explícita.
